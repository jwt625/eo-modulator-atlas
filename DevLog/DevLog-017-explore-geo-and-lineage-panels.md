# DevLog-017: geography and lineage panels

User request (2026-10-04): propose and implement two more explore panels, one geolocation
focused and one academic-lineage focused.

## Data available (checked)

- Per paper: `countries_derived` (ISO alpha-2 from affiliations, 18 countries), `regions_derived`,
  `orgs_affil` (org name, country, region), ordered `authors` (all 138 papers).
- No geocoding, cities or advisor/student records exist. Lineage must be derived and labelled as such.

## Proposal

k. Geography: proportional-symbol world map (bubble area = papers or devices per country,
   centroid positions) plus papers per year stacked by region. Bubbles instead of a choropleth:
   area-filled countries overweight large countries and hide HK/SG. Hover: counts, EO-material
   mix, top affiliated organizations in that country. Multi-country papers count once per country
   and once per region.
l. Academic lineage: PI timeline. Last author is the PI proxy (one row per PI, markers per paper
   as last author, coloured by EO material). Candidate lineage arrow A -> B when B appears in the
   first half of the author list of A's paper before B's first last-author paper in the database.
   Dashed links: other co-authorships between PIs. Prototype on 138 papers: 83 PIs, 4 candidate
   lineage arrows (incl. Loncar -> Cheng Wang, Loncar -> Mian Zhang), 25 PI-PI co-authorships.
   Name matching by normalized first + last name token. Not verified advisor relations; stated in
   the panel tooltip.

Map geometry: Plotly `world_110m.json` vendored into `app/static/topojson/` (fetched once from
cdn.plot.ly/un/, 285 KB) so the static site does not depend on the CDN; centroids generated into
`app/src/lib/geo-centroids.ts` from Plotly `world_50m.json` (fetched once; has HK and SG, which the
110m file lacks; not committed).

## Limits

- Lineage is an author-order heuristic, not advisor data; name matching by first + last name token can merge or split
  people. Countries come from affiliations per paper (no per-author mapping), so a paper counts in every country listed.
- European bubbles overlap at world scale; hover and Plotly zoom separate them.
