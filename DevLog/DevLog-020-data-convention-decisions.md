# DevLog-020: data convention decisions and application

User answers (2026-10-05) to the open decisions collected in DevLog-014/015/016 and the
README follow-ups. Verbatim intent, then the rule adopted here. Where the user said the
answer is obvious from the project goal, the rule below is the coordinator's decision.

## Decisions

| # | Question (source) | User answer | Rule adopted |
|---|---|---|---|
| 1 | `year` / `published_on` for preprint-sourced rows (014 #1, 015 #1) | use earliest | `published_on` = earliest full public-availability date: arXiv v1 submission, Crossref `published-online`, `posted` (print-issue cover dates `published-print`/`issued` only when none of these exists, because cover dates can precede availability). `year` = earliest year over all candidates incl. print/issued (exceptions where they differ: powell2024 year 2024 from the CLEO 2024 abstract vs published_on 2025-05-01; chen2022 print cover 2022-02-01 vs online 2022-02-02). Sources in `references/<id>/` (crossref.json, arxiv.json). |
| 2 | Author-list source (015 #2) | Crossref; dedup as much as possible | `authors` from the Crossref record when it lists authors; otherwise the cached source. People deduplicated across papers with a `person_id` (ORCID when Crossref gives one, else normalized name plus shared affiliation/coauthor evidence). |
| 3 | arXiv identity form (015 #3) | DOI if it exists, else arXiv URL | `url` = `https://doi.org/<doi>` when a version-of-record DOI exists (arXiv DataCite DOIs excluded), else `https://arxiv.org/abs/<id>` (unversioned). `arxiv_id` keeps the version whose pages the evidence locators cite. `source_type`/`venue` describe the DOI version when there is one. DOIs for arXiv-only rows searched in Crossref (exact title + first-author match only). |
| 4 | Redistribution for unverified-license arXiv rows (015 #4) | it is on arXiv; tracking is fine; we do not redistribute directly | Cached arXiv PDFs stay tracked. `license` = the arXiv license of the cached version from the arXiv OAI-PMH record (`arXiv-nonexclusive-1.0` or the CC license); `redistribution` = `open_license_ok` for CC-BY, CC-BY-SA, CC0; `restricted_local_only` for arXiv-nonexclusive and any NC or ND licence (same rule for journal copies; coordinator decision after the final audit, M2). No `unknown` for arXiv rows. |
| 5 | Schema vocabulary (015 #5, 016) | add; bands use international standards | Add `soi_strip`, `lnos_rib`. `band` per ITU-T G.Sup39 (O 1260-1360, E 1360-1460, S 1460-1530, C 1530-1565, L 1565-1625, U 1625-1675 nm) and ISO 20473 outside it (visible 380-780 nm, near-IR, mid-IR 3-50 um). Re-derived from `wavelength_nm` where present. `er_type` gains a value for passive resonance-dip depth. |
| 6 | suceava2025, giambra2021 identity (014 #3-4, 015 #6) | DOI first, arXiv second | Same rule as #3. |
| 7 | dc/rf Vpi cutoff and other unstated rules (014 #1) | 1 GHz; obvious from the project goal | Vpi measured below 1 GHz -> `vpi_dc_v` (frequency kept); at or above 1 GHz -> `vpi_rf_v` + `vpi_rf_freq_ghz`. Cleanroom the paper says was used -> `foundry_or_fab`. `discovered_via` vocabulary normalized and documented. `verified_on` = date the row was last checked against the source (instructions fixed). |
| 8 | Schema proposals (014 #2, batch SPEC_PROPOSALS.md) | dedup and adopt per project goal | Consolidated list below; adopted items implemented in schema, validator, views and app. |
| 9 | Organization names (014 #6) | research the orgs' own preferences | Name = the organization's own preferred English name (its website / ROR record), source stored per org; countries from the org's own address. |
| 10 | zhang2023 mixed row (014 #5) | decide | Split per convention (d): different physical devices get separate rows. |
| 11 | Tracked publisher PDFs (004, WORKBOARD R1) | tracking is fine | Policy closed: tracked as now; OFC conference PDFs stay local-only as already set. |
