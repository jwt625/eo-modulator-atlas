# Paper retrieval inbox

Current list: [2020–2026 retrieval requests](../../data/_staging/discovery_2026_10_02/RETRIEVAL_REQUESTS.md).

Use the exact `<paper_id>.pdf` names in that list. Supporting information can be
saved as `<paper_id>_supplement.pdf`, and published data as `<paper_id>_data.zip`.
Keep any correction separate, e.g. `lu2020_correction.pdf`. If the file is an
accepted manuscript rather than the final article, mention that when handing it
over. Files in this inbox are local and git-ignored; this README is the exception.

After receipt, Codex will check identity/version, hash and extract the source,
record provenance, and remove the matching retrieval request. Do not overwrite
an existing reference PDF with a different version without recording the change.
