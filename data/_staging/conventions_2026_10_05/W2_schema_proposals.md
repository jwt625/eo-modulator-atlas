# W2: consolidated schema / interface proposals (read-only analysis, 2026-10-05)

Scope: every schema, enum, convention and validator proposal in the 28 `data/_staging/*/SPEC_PROPOSALS.md` files, the
interface follow-ups in DevLog-004 / 014 / 015 / 016 / 019, and proposal notes in `data/_staging/p4_*` and `p5_*`
reports. Deduplicated into one list with a recommendation each. Simulation-contract (`sims/SPEC.md`) items are in a
separate section at the end (engine owner).

Source abbreviations: `pilot` = `data/_staging/pilot_chen2022/SPEC_PROPOSALS.md`; `pN_MM` = `data/_staging/pN_MM/SPEC_PROPOSALS.md`
unless a file is named (`p4_03/BATCH_REPORT`); `DL004` = `DevLog/DevLog-004-data-lane-progress.md` (same for 014, 015,
016, 019, 020). "n" = number of distinct batch files raising it (DevLog mentions listed, not counted).

Data snapshot: counts come from the working-tree `data/devices.csv` (403 rows), `data/papers.csv` (184 rows) and
`data/evidence/*.yaml` (174 files) as read on 2026-10-05, while the coordinator's uncommitted edits for the decided items
(convention l-p, soi_strip, lnos_rib, resonance_dip) were already partly applied. All row counts are grep/heuristic
based unless marked otherwise; "grep" counts are upper bounds that include false positives where noted.

Fill strategy codes: (a) mechanical from existing columns/tags/notes; (b) needs re-reading sources; (c) schema-only for future rows.
