# Schema / skill proposals from batch p3_12 (not applied)

- Channel arrays (hu2026a): eight nominally identical MZMs on one chip became eight rows that differ only in Vpi. Proposal: allow a row with a range (`vpi_dc_v_min`/`_max`) or an `array_channels` field plus a statistic basis, or state in the skill that one representative row with the range in notes is preferred.
- Package- and system-level metrics have no columns: flip-chip bond loss and inter-channel crosstalk (wang2026b), switch rise/fall time and optical crosstalk, array fiber-to-fiber loss and laser-bonding penalty (hu2026a), facet transition loss (niels2025a). Proposal: a `system_metrics` free-text column or a small companion table keyed by device_id.
- Preprint-versus-journal handling for entries that also have a Crossref record (chen2023a, tan2024): `crossref.json` exists for the journal version, while the cached numbers come from the arXiv version. The skill's convention (k) ties license/published_on to crossref.json; proposal: state explicitly that a Crossref licence never transfers to a preprint-sourced row, and add a `numbers_from_version` column (preprint vN | version of record).
- Batch-CSV `source_type = journal` for papers whose cached source is an arXiv version (niels2025a): the validator accepts either; proposal: prefetch should write the cached version into the batch CSV or the skill should say the row follows the cached source.
- Basis for dimensions stated in text: designs/fabrication dimensions from the text were entered with basis `design_target` (consistent with kim2025 in p3_04); the pilot chen2022 used `measured`. Proposal: add a basis value such as `stated_dimension` or fix one convention in the skill.
- Inferred drive/convention (hu2026a, chen2023a): evidence entries with basis `derived` were added for `drive` and `vpi_convention`; confirm that evidence entries for non-evidence columns are accepted by build_views.
- Resonator metrics: `q_loaded` is used when the paper says only "quality factor" (tan2024); proposal: `q_type` (loaded|intrinsic|unspecified). Tuning sign (negative resonance shift per volt, Fig. 6(c) of tan2024) is lost in `tuning_nm_per_v`; proposal: keep sign or add a polarity note convention.
- Hybrid LN-on-Si (unetched LN coupon on a Si strip) uses `lnoi_loaded_si`; hybrid LN-on-SiN micro-transfer-printed uses `lnoi_loaded_sin` (as in vanackere2023). Fine, but the enum descriptions do not say which layer is the waveguide; proposal: add one line each to the schema.
- `electrode_type` has no value for a non-traveling-wave electrode pair of a printed coupon whose type is unstated (niels2025a left empty) or for ring electrodes (tan2024 left empty).
- `discovered_via` tokens `web_search`, `author_group_followup` and `continuation_2026_10_02` are from the batch CSV and entered verbatim (as in p3_02); they are not in the documented vocabulary.
- Duplicate organizations across staged batches (ECNU, ULB, CityU, Fudan) are copied identically; a merge-time dedup across staging directories would remove the coordination burden.
