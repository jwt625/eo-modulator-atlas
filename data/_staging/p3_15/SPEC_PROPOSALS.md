# SPEC / schema proposals from batch p3_15 (not applied)

- No column for linearity metrics (sia2022: SFDR 75, 91, 95, 82 dB Hz^(2/3) at 1, 3, 5, 7 V reverse bias; third-order intermodulation setup with 0.995 and 1.005 GHz tones). SFDR is in the row notes only. Proposal: `sfdr_db_hz23` (plus tone frequency) and `analog_link` tag vocabulary.
- Transmitter-level metrics have no columns (kawahara2025: total DC power 50 mW, active footprint 0.66 mm^2, driver technology). Only `energy_per_bit_fj` and `driver` carry part of it. Proposal: `power_total_mw`, `footprint_mm2`.
- Review or compact-model papers (huang2026a) have no row type: all numbers are measured values of other groups' devices or calibrated model outputs. Handled as no_device_rows. Proposal: a paper-level `paper_kind` (primary_device | review_or_model | system | material) so such papers are explicit rather than inferred from an empty device list; model outputs on a cited device would need a `basis: simulated` row linked to the source device.
- `bias_for_vpi_v` sign: reverse bias entered as negative (follows earlier batches), but several papers (sia2022 Vbias 1 to 8 V; shen2021, hu2023 gate/bias) quote positive reverse-bias magnitudes; the convention is not written in the schema header. Proposal: add convention (l): reverse bias = negative, with the evidence note stating the paper's own sign.
- `integration` enum has no value for foundry-fabricated passive silicon with post-process deposition at a university cleanroom (hsu2024: Intel fab ring plus HfO2/ITiO gate at Oregon State) or for research-institute pilot-line fabrication (AIST 300 mm in kawahara2025). `other` used.
- `eo_material` has one silicon value; MOSCAP rings with a TCO gate (hsu2024) modulate through accumulation in both Si and ITiO. `silicon_plasma_dispersion` used, TCO named in tags. Proposal: tag vocabulary `tco_gate`, or a `silicon_moscap` value.
- `device_class` has no value for ring-assisted MZMs (sia2022; `mzm` used with tag ring_assisted_mzm, Vpi*L convention `unspecified` because the paper does not define it) or for a modulator-plus-driver transmitter (kawahara2025; `mzm` used with tag transmitter).
- `electrode_type` has no value for an unterminated high-impedance electrode with periodic series inductors between short junction segments (kawahara2025); `other` used.
- Bandwidth labels read on a curve that is a co-simulation fit extending beyond the measured sweep (kawahara2025: sweep 1 to 40 GHz, labels 50 and 55 GHz): entered with basis `extracted_from_figure` plus `bw_measured_to_ghz` = 40. Convention (c) covers bounds and instrument limits but not a fitted-curve crossing beyond the sweep; confirm this is the intended handling.
- Qualifier wording such as 'remains as high as 0.8 V cm' (hu2023), 'approximately 42.5 GHz' next to a labelled 42.5 (hu2023): the schema offers only lt, gt, approx; 'as high as' was entered without a qualifier and the exact wording is in the evidence note.
- `eo_film_thickness_nm` for silicon devices: used for the Si device-layer or rib height (220 nm, 300 nm); the column description is EO-film oriented and not stated for silicon.
- Preprint versus version-of-record title policy: hu2023 and shen2021 preprint titles differ from the Crossref titles (Crossref titles used in papers.csv, preprint titles quoted in notes). Not written in the contract; confirm.
- BATCH_INSTRUCTIONS text says verified_on 2026-10-01 while the task for this batch said 2026-10-02 (used). Crossref lists a CC-BY VoR license for hsu2024, hu2023 and kawahara2025 while this batch rule keeps license empty for the cached preprint; the VoR license is only in the notes.
